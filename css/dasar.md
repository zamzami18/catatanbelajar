\# Catatan CSS



\## Apa itu CSS?

Bahasa untuk mengatur tampilan halaman web: warna, ukuran, dan tata letak.



\## Contoh

```css

h1 {

&#x20; color: blue;

&#x20; font-size: 32px;

}



body {

&#x20; background-color: lightyellow;

}

```



\## Properti yang sering dipakai

\- `color`: warna teks

\- `font-size`: ukuran huruf

\- `background-color`: warna latar

\- `margin` dan `padding`: jarak luar dan dalam
