\# Perintah Git Harian



\- git clone URL: menyalin repo dari GitHub ke komputer

\- git status: melihat perubahan yang belum di-commit

\- git add .: memasukkan perubahan ke staging

\- git commit -m "pesan": menyimpan snapshot perubahan

\- git push: mengirim commit ke GitHub

\- git log --oneline: melihat riwayat commit
